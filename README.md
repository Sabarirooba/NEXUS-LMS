# NEXUS-LMS
Authetication Module & User Management Module

**Project Description**
This module is part of the NEXUS LMS (AI-Powered Learning Management System).
The module provides user aunthetication and profile management functionalities using Streamlit.

**Features**
✅ User Login
✅ Student Registration
✅ Forgot Password
✅ User Profile
✅ Edit Profile
✅ Logout Functionality
✅ Role-Based Dashboard Navigation
     🌟 Student Dashboard
     🌟 Instructor Dashboard
     🌟 Admin Dashboard

**Technology Stack **
✅ Python
✅ Streamlit

**Project Structure**
authentication_module.py
README.md

**Installation**
pip install -r requirements.txt

**Run Application**
streamlit run authentication_module.py
